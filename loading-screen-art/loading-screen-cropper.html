A faithful mock of the game's loading screen (LoadingScreenPrefab.prefab, same positions, fonts, sizes and gold gradient) with every line it shows, in the order it shows them. Type your own line in any row and it plays on the screen above.

Cropping: drag the screen to move the art, use the slider or your mouse wheel to zoom. The numbers are the crop in the art's own pixels, so they can go straight into the game. Saving the PNG works when you open the file on your computer; the hosted page blocks downloads.

About the art: this is the full-resolution Bullseye Bounty Hunter art (Zed Edge, 1572 x 2193) from CCG_209.psd. The art is a tall card, so full screen crops it to her face and shoulders the way the game crops a background, and framed shows the whole card over a blurred copy of itself.

Every line, in order

They are all real steps. Each line is set by the code at the moment that step starts, so the text is free to change but it will still appear at that moment and for as long as that step takes. Rows marked Only sometimes are skipped when there is nothing to download.

The game adds to your text. It uppercases it and appends ... and either a count like 12/48 or 120.4 MB / 512.0 MB. Don't put "... " (dots then a space) inside a line, because the screen splits the text there.

The easiest swap needs no code. The line text is a key in the localization table, so rows marked in table can be renamed by editing only the English value in Assets/Localization/ChronoCCG_StringTable_en.asset. Rows marked not in table need an entry added there first (or the phrase changed in code).
